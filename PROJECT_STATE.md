# État du projet - Mastering IA

## Version actuelle
V13

## But de l'application
Créer une application web mobile de mastering IA capable :
- d’analyser un son
- d’embellir le rendu audio
- d’appliquer un final master
- d’exporter le fichier final
- de vendre des générations
- de gérer une comptabilité simple
- de préparer les déclarations URSSAF trimestrielles

## Ce qui fonctionne déjà
- Interface frontend en ligne
- Backend en ligne
- Espace admin
- Connexion admin
- Espace client
- Inscription client
- Connexion client
- Solde de générations
- Analyse audio
- Traitement voix + instru
- Décompte de générations côté client
- Tables ventes / dépenses
- Tables utilisateurs / événements générations
- Ajout manuel de générations par admin
- Rapport URSSAF lisible
