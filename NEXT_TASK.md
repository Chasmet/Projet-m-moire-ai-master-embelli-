# Prochaine tâche

## Nom
V10.1 rapports admin automatiques

## Objectif
Rendre l’espace admin plus intelligent et plus rapide à utiliser en automatisant le rapport trimestriel.

## À faire
- charger automatiquement le rapport du trimestre courant à l’ouverture de l’admin
- recalculer automatiquement le rapport après ajout d’une vente
- recalculer automatiquement le rapport après ajout d’une dépense
- afficher directement :
  - période courante
  - chiffre d’affaires à déclarer
  - dépenses internes
  - marge interne
  - texte du rapport
- garder le bouton manuel seulement comme option secondaire si besoin

## Important
Ne pas casser :
- l’analyse
- le résumé IA
- le traitement
- le téléchargement du fichier final
- les packs générations
- le wording embellissement + final master
- le login admin déjà validé
- l’enregistrement manuel des ventes
- l’enregistrement manuel des dépenses

## Après cette étape
- connexion client
- inscription client
- générations par utilisateur
- base du paiement Revolut
