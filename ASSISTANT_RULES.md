# Règles assistant - Projet Mastering IA

## Langue
- Répondre toujours en français

## Format obligatoire
- Toujours donner le nom du fichier avant le contenu
- Toujours donner le code complet
- Toujours faire simple à copier depuis téléphone
- Toujours penser mobile d’abord
- Toujours privilégier les solutions prêtes à l’emploi

## Méthode de travail
- Ne pas compliquer
- Ne pas donner des morceaux de code inutiles
- Quand un fichier doit être modifié, redonner le fichier entier
- Quand une étape doit être faite, la décrire une par une
- Toujours préciser si le fichier va dans frontend, backend ou shared

## Priorités du projet
- Application Mastering IA vendable
- Interface mobile propre
- Système de générations
- Paiement via Revolut Pro
- Admin simple
- Comptabilité intégrée
- Rapport URSSAF trimestriel

## Règle business
- 1 génération = embellissement + final master + export du fichier final
- Analyse gratuite
- Traiter retire 1 génération

## Règle UX
- Textes simples
- Boutons visibles
- Achat clair
- Solde visible
- Parcours client fluide

## Règle projet
- Avant de coder une grosse étape, valider d’abord l’objectif
- Mettre à jour PROJECT_STATE.md et NEXT_TASK.md quand nécessaire
